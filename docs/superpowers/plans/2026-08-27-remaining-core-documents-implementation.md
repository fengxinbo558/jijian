# 机鉴剩余三份核心文档实施计划

1. 盘点当前代码、接口、数据表、角色、测试和已有报告，建立能力真实性清单。
2. 只使用模型厂商、标准组织和数据集维护方的官方资料，形成可追溯的模型与数据来源。
3. 编写技术方案，覆盖采集、关联、AI调查、RAG、Agent、现场协同、安全、部署、容量和生产差距。
4. 编写模型选型报告，覆盖任务拆分、候选池、评分矩阵、部署策略、Embedding/Reranker、供应商适配与POC门禁。
5. 编写评测与基线报告，覆盖数据分层、盲测、指标、红队、性能、人工评审、发布门禁和当前实测结果。
6. 使用统一构建脚本生成 DOCX，逐页渲染检查并修复版式问题。
7. 运行最终文件、结构、链接和版本控制检查，只提交本次新增文档与构建脚本。
