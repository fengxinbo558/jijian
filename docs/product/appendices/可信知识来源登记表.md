# 机鉴可信知识来源登记表

**版本：** V0.1  
**状态：** 建设中  
**用途：** 先登记来源，再提炼候选知识；登记不等于知识已经审核发布。

## 来源等级

- A：国际标准、官方项目文档、厂商官方技术资料；
- B：许可证明确的官方样例、公开测试数据、客户正式SOP；
- C：经过审核的历史工单和现场经验；
- D：博客、论坛、口述推测和模型生成线索，只能辅助发现，不可直接发布。

## 发布门禁

任何候选知识只有同时满足以下条件，才能进入已发布RAG知识库：

1. 来源链接、版本或发布日期可追溯；
2. 适用厂商、型号、系统或版本明确；
3. 支持证据、竞争原因和反证完整；
4. 包含缺失信息、验证步骤和停止条件；
5. 不包含未经授权的写操作；
6. 经过人工内容审核和检索测试；
7. 发布后保留版本、反馈和回滚能力。
